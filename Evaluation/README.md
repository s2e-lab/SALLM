# Evaluation Pipeline

This directory contains scripts and configuration for evaluating the security of code generated by LLMs, as well as the canonical insecure samples from the SALLM dataset.

## Directory Structure

- `Filtered_Output/`: Contains JSONL files with generated code from various models. Each line should have an `id`, `technique`, `source`, and `output` (list of code candidates).
- `temp/`: A temporary workspace where code is extracted from JSONL files before evaluation.
- `TestModelsResults/`: Output directory for evaluation results of **generated code** (CSV format).
- `TestResults/`: Output directory for evaluation results of the **dataset's insecure samples** (CSV format).
- `CWE_Results/`: Aggregated or historical results organized by CWE.
- `config.py`: Configuration file for paths used by the evaluation script.

## Core Scripts

### `run_tests.py`

This is the main evaluation entry point. It has been optimized for high performance using a **Base Image + Volume Mounting** strategy.

#### Key Features:
- **Build Once, Run Many**: It identifies unique prompts and builds a single Docker base image for each. This image is reused across all models and rounds for that prompt.
- **Volume Mounting**: Code candidates are mounted into the container at runtime, avoiding expensive image rebuilds for every test case.
- **Parallel Execution**: Uses `ProcessPoolExecutor` to run multiple containers in parallel.
- **Polyglot Support**: Automatically detects and handles both Python (`.py`) and Java (`.java`) files.

#### Configuration Flags:
Located at the top of `run_tests.py`:
- `DEBUG`: If `True`, prints detailed Docker build and run logs.
- `MAX_WORKERS`: Number of parallel workers (default: 4).
- `RUN_TESTS_ON_GENERATED_CODE`: Set to `True` to evaluate model outputs in `Filtered_Output/`, or `False` to test the dataset itself.
- `TEST_MODE`: If `True`, only processes a small subset (5 files) for verification.

#### Usage:
```bash
# Ensure Docker is running
python3 Evaluation/run_tests.py
```

## Setup & Dependencies
- **Docker**: Must be installed and running.
- **Python 3.x**: With `tqdm` installed (`pip install tqdm`).
- **Disk Space**: Evaluation involves building several small Docker images. Ensure sufficient disk space is available.
